Gotlandstider public content feeds

These unauthenticated, read-only JSON resources expose the same published content used by www.gotlandstider.se. Draft source content is not included.

Endpoints

  • GET /generated/content/articles.json All published Gotlandstider articles in reverse chronological order.
  • GET /generated/content/featured.json The published articles selected for featured placement.
  • GET /generated/content/homepage.json The featured video and complete pool of published, non-featured homepage archive candidates.

Machine-readable discovery

  • RFC 9727 API catalog
  • OpenAPI 3.1 service description
  • JSON-LD site description

Responses may be cached and change whenever new content is published.
